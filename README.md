# 🎵 JavaScript Music Player 🎧

🎶 Welcome to our JavaScript Music Player! This web application is developed using HTML, CSS, and JavaScript. It provides a simple and interactive platform to play music, control volume, navigate between songs, and manage a playlist. Enjoy your favorite music with an easy-to-use interface! 🎵

[Live](https://khushalraut706.github.io/Music-web/)

## Features

- **Play/Pause Music:**
  - Play and pause songs using interactive controls.
  - Switch between play and pause buttons.

- **Previous and Next Song:**
  - Move to the previous or next song in the playlist.
  - Automatically repeat the playlist after the last song.

- **Music Progress Bar:**
  - Displays the current playback progress.
  - Click on the progress bar to jump to a specific part of the song.

- **Volume Control:**
  - Adjust the music volume using the range slider.

- **Playlist:**
  - Displays all available songs.
  - Select any song directly from the playlist.
  - Highlights the currently playing song.

- **Automatic Song Change:**
  - Automatically plays the next song when the current song ends.

- **Time Display:**
  - Shows the current playback time and total song duration.

## Tech Stack

1. **HTML5:** Used for creating the structure of the music player and its controls.
2. **CSS3:** Used for styling the music player, buttons, playlist, progress bar, and layout.
3. **JavaScript:** Used to handle music playback, playlist management, volume control, and user interactions.
4. **HTML Audio Element:** Used to load and play audio files directly in the browser.

## APIs Used

1. **HTML Audio API:** Used to play, pause, and control audio files through the browser.
2. **JavaScript DOM API:** Used to access and update HTML elements dynamically.
3. **JavaScript Event Listeners:** Used to handle button clicks, volume changes, progress bar clicks, and audio events.
4. **HTML Media Events:** Used to track playback progress and detect when a song ends.
